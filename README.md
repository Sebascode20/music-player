## Overview

![screenshot](./Capture-Music%20Player.png)

A fully functional and responsive music player web application built with vanilla HTML, CSS, and JavaScript. The player features a sleek, modern card-based design with a dark theme and interactive controls. Users can play, pause, skip forward and backward through a playlist, and track music progress with a custom progress bar displaying current and total duration times.

### What I learned

- **DOM Manipulation**: Gained solid experience working with the DOM API to handle user interactions and update the UI dynamically without page reloads.
- **Audio Element API**: Learned to leverage the HTML5 Audio API for comprehensive music playback control, including play/pause functionality, duration management, and real-time time updates.
- **CSS Styling & Animations**: Enhanced my skills in creating responsive designs with CSS custom properties (CSS variables), flexbox layouts, and custom-styled range input elements for the progress bar.
- **Event Handling**: Implemented multiple event listeners to create a smooth user experience, including click events for buttons and input events for progress tracking.
- **State Management**: Practiced managing application state effectively by tracking the current song index and dynamically updating UI elements based on song changes.
- **Code Organization**: Wrote clean, maintainable JavaScript with meaningful variable names and well-structured functions for better code readability.

### Useful resources

- [MDN Web Docs - HTML Audio Element](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/audio) - Comprehensive documentation on audio properties, methods, and events

- [CSS-Tricks - Styling Input Range](https://css-tricks.com/styling-cross-browser-compatible-range-inputs-css/) - Excellent tutorial on custom styling for range inputs across different browsers

## Features

- **Play/Pause Control**: Toggle between playing and pausing the current track
- **Next/Previous Navigation**: Skip to the next or previous song in the playlist
- **Progress Bar**: Interactive range slider to seek through the track and visualize progress
- **Time Display**: Real-time display of current playback time and total song duration
- **Playlist Management**: Seamlessly switch between multiple songs with dynamic UI updates
- **Responsive Design**: Mobile-friendly layout that adapts to different screen sizes
- **Custom Styling**: Modern dark theme with gradient background and custom-styled controls
- **Album Cover Display**: Album artwork changes dynamically with each song selection
